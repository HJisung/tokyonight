# 사용 피드백 기록

## 2026-11-13 · v0.1 첫 수동 테스트 (macOS, `tauri dev`)

사용자가 실제 창에서 직접 눌러 본 결과다. 아직 반영하지 않았다.

### 잘 되는 것

- 폴더 열기, 파일 트리 기본 동작.
- 한글 입력과 자동 저장. 다른 편집기에서 고쳐 저장하면 앱에 바로 반영된다.
- 분할(좌우·상하), 같은 문서 동기화, 워크스페이스 탭.
- 외부 변경 충돌: VS Code에서 입력하고 앱에서도 입력한 상태로 VS Code에서 저장하면 충돌 띠가 뜬다.
- 검색과 드래그 복사는 동작한다(단, UI는 아래 참고).

### 고칠 것

1. **체크리스트**: `- [ ]`가 동작하지 않는 것 같다. 그 밖의 Markdown 서식은 되는 듯하다.
2. **서식 ↔ 원문 전환 시 커서**: 전환하면 커서가 이전 모드의 위치에 그대로 있어 부자연스럽다. 원문 → 서식, 서식 → 원문 양쪽 모두 같은 증상.
3. **표**
   - 표의 "원문" 버튼(표만 원문으로 바뀌는 기능)은 필요 없을 듯하다.
   - 행·열 추가/삭제가 직관적이지 않다.
   - 방향 자체가 틀린 것 같다. 표는 Markdown처럼 다루지 말고 노션처럼 드래그 등으로 직접 조절할 수 있어야 한다.
   - "표 삽입"이 어디 있는지 찾지 못했다(기존 md 파일의 표로만 테스트함).
4. **충돌 띠 문구**
   - 경고 문구: "외부에서 현재 파일이 변경되었습니다" 쪽으로.
   - 버튼: "디스크 내용 불러오기" 대신 "외부 변경 덮어쓰기"(제안 표현 그대로 기록. 의미 확인 필요) / "내 내용으로 덮어쓰기".
5. **검색·드래그 UI**: 동작은 하지만 직관적이지 않다. UI 피드백 때 한꺼번에 다룬다.

### 테스트하지 못한 것

- 앱을 껐다 켜는 방법을 몰라 세션 복원, 임시 메모 복구, `⌘S`로 임시 메모를 파일로 저장하는 흐름은 확인하지 못했다. → 종료·재실행 방법 안내가 필요하고, 이 항목들은 다시 테스트해야 한다.

### 전체 방향

- UI가 너무 투박하다.
- 처음 생각은 JetBrains + Obsidian 느낌이었는데, 써 보니 사용성은 노션 쪽이 더 좋을 것 같기도 하다. (아직 결정은 아님)
