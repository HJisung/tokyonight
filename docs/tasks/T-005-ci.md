# T-005 CI/CD: macOS·Windows에서 check·빌드, 릴리스 초안

- 마일스톤: M0 하네스·개발 환경
- 상태: ready
- 검수: 승인 (2026-11-12)
- 의존: T-004
- 담당: 구현자

## 목표

두 대상 OS에서 매 push마다 검증이 돌게 한다.

## 범위

- CI: `develop`, `main` 대상 PR과 푸시마다 macOS·Windows 매트릭스에서 `pnpm check`와 `pnpm tauri build`.
- CD: `main`에 병합되면 두 OS의 설치 파일을 빌드해 GitHub 릴리스 초안에 올린다(서명 없음).
- `develop`, `main` 브랜치 보호 규칙(PR 필수, CI 통과 필수) 설정 방법을 문서화하고 사용자 승인 후 적용한다.
- Rust·pnpm 캐시.

## 범위 밖

- 코드 서명·공증, 자동 업데이트(T-062).

## 완료 기준

- `develop` 대상 PR에서 두 OS 작업이 모두 통과한다.
- 릴리스 워크플로는 문법 검사를 통과하고, 실제 실행은 첫 `main` 병합 때 확인한다.
