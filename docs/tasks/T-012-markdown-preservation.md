# T-012 Markdown 보존 방식 결정과 왕복 테스트 코퍼스

- 마일스톤: M1 미정 사항 결정
- 상태: proposed
- 검수: 대기
- 의존: T-011
- 담당: 구현자+리뷰어

## 목표

모드 전환·저장 과정에서 지원하지 않는 문법을 잃지 않는 방식을 정하고, 이를 검증할 기준 문서 묶음을 만든다.

## 범위

- 지원 문법 범위(CommonMark + GFM 표·체크리스트·각주)와 미지원 내용(HTML, frontmatter, 수식, MDX 등)의 취급을 정한다.
- `fixtures/markdown/`에 왕복 테스트용 문서를 모은다(줄바꿈 CRLF/LF, 들여쓰기, 목록 표식 차이 포함).
- '열고 수정 없이 저장하면 바이트 단위로 동일'을 기본 원칙으로 검토한다.
- `docs/decisions/0002-markdown-preservation.md`.

## 범위 밖

- 편집기 구현.

## 완료 기준

- 결정 문서와 코퍼스가 있고, 왕복 테스트의 통과 기준이 명시되어 있다.
