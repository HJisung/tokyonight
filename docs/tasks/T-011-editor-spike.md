# T-011 편집기 라이브러리 선정 스파이크

- 마일스톤: M1 미정 사항 결정
- 상태: done
- 의존: T-003
- 담당: 구현자+리뷰어

## 목표

Markdown 서식 편집과 원문 편집을 함께 만족하는 편집기 기반을 실측으로 고른다.

## 범위

- 후보: CodeMirror 6(라이브 프리뷰 방식), ProseMirror 계열(Milkdown/Tiptap), Lexical. 후보별 최소 프로토타입.
- 평가 기준: 원문 무손실 왕복, 표·각주·체크리스트 지원 난이도, 한 문서를 여러 영역에서 동시에 편집, 한글 IME 입력, 큰 파일(예: 1MB) 반응성, 번들 크기.
- 결과를 `docs/decisions/0001-editor.md`에 기록한다.

## 범위 밖

- 실제 기능 구현. 프로토타입 코드는 병합하지 않는다.

## 완료 기준

- 기준별 비교표와 추천안이 있고 사용자가 선택했다.
- README의 '아직 정하지 않은 것'에서 해당 항목을 정리했다.

## 작업 기록

- 2026-11-12: 프로토타입 비교 없이 사용자가 CodeMirror 6 라이브 프리뷰로 결정. Tiptap은 대안으로 유지. `docs/decisions/0001-editor.md`.
