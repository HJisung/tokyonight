# T-041 워크스페이스 탭

- 마일스톤: M4 작업 화면 (MVP)
- 상태: proposed
- 검수: 대기
- 의존: T-040
- 담당: 구현자

## 목표

위쪽 탭으로 워크스페이스를 전환하고, 탭마다 열린 문서와 분할 배치를 따로 기억한다.

## 범위

- `src/features/workspaces/`. 워크스페이스 만들기, 이름 변경, 삭제(마지막 하나는 삭제 불가), 순서 변경(dnd-kit), 전환. 단축키 포함.
- 워크스페이스마다 자기 분할 트리를 가진다. 문서 저장소는 공유하므로 전환해도 저장하지 않은 편집이 유지된다.
- 삭제할 때 그 워크스페이스에만 열려 있는 수정된 문서가 있으면 묻는다.

## 범위 밖

- 재실행 후 복원(T-042). MVP에서는 앱을 닫으면 워크스페이스 배치가 사라진다.

## 완료 기준

- 단위 테스트: 전환 후 각 워크스페이스의 배치가 유지된다, 삭제·순서 변경.
- `pnpm check`가 통과한다.
