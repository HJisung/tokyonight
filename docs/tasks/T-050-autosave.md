# T-050 자동 저장

- 마일스톤: M5 저장·안정성·검색
- 상태: draft
- 검수: 대기
- 의존: T-024, T-014
- 담당: 구현자

## 목표

작업 내용을 자동으로 저장한다.

## 범위

- 저장 시점(입력 멈춤, 포커스 이동, 종료 시), 실패 시 표시.
- 외부 변경과 겹치면 T-052 흐름으로 넘긴다.

## 범위 밖

- 없음

## 완료 기준

- 입력 후 앱을 강제 종료해도 정해진 시간 이전의 내용은 디스크에 있다.
