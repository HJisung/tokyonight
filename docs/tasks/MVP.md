# MVP

2026-11-12 사용자 결정. 제품의 차별점(한 창에서 여러 문서를 분할해 편집하고 워크스페이스로 전환)이 보이는 최소 범위입니다.

## 포함

폴더 열기, 파일 목록, TXT·MD 편집과 저장, 임시 메모, 좌우·상하 분할, 워크스페이스 탭.

## MVP 뒤로 미룸

표·각주, 자동 저장, 재실행 시 복원, 검색, 외부 변경 감지, 끌어다 놓기 복사, 최근 작업, 배포.
