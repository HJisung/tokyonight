# T-024 일반 텍스트 편집

- 마일스톤: M2 파일·문서 코어
- 상태: draft
- 검수: 대기
- 의존: T-011, T-021
- 담당: 구현자

## 목표

TXT와 확장자 없는 파일을 일반 텍스트로 편집한다.

## 범위

- 선정된 편집기 기반으로 일반 텍스트 모드.
- 확장자 없는 파일의 이름을 바꾸지 않는다.
- `Ctrl+S`/`⌘S` 저장.

## 범위 밖

- 없음

## 완료 기준

- 열기→수정→저장→다시 열기에서 내용·줄바꿈이 보존된다.
- 한글 IME 입력이 정상이다.

## 작업 기록

- (진행하면서 결정·검증 결과·남은 문제를 여기에 적는다)
