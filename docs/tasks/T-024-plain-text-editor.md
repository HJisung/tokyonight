# T-024 일반 텍스트 편집 (CodeMirror 6)

- 마일스톤: M2 파일·문서 코어 (MVP)
- 상태: ready
- 검수: 승인 (2026-11-12)
- 의존: T-021, T-010
- 담당: 구현자

## 목표

TXT와 확장자 없는 파일을 열어 편집하고 저장한다. 이후 Markdown 편집의 기반이 된다.

## 범위

- `src/features/editor/`에 CodeMirror 6 기반 `DocumentEditor` 컴포넌트. 문서 ID를 받아 문서 저장소와 양방향으로 연결한다.
- 같은 문서를 보여 주는 편집기가 여러 개여도 내용이 즉시 같아진다. 커서와 스크롤은 뷰마다 따로다.
- `⌘S`/`Ctrl+S` 저장, 수정됨 표시, 실행 취소·다시 실행, 줄바꿈 표시(자동 줄바꿈).
- 확장자 없는 파일의 이름을 바꾸지 않는다. 줄바꿈 형식을 보존한다.
- 확인용으로 본문 영역에 문서 하나를 띄우는 임시 연결(파일 열기 대화상자).

## 범위 밖

- Markdown 서식 표시(T-030), 찾기·바꾸기, 분할(T-040).

## 완료 기준

- 테스트: 두 편집기 동기화, CRLF 파일을 열어 한 글자 고치고 저장하면 나머지 바이트가 동일.
- 수동 확인: 한글 입력 중 글자가 깨지거나 중복되지 않는다(PR에 기록).
- `pnpm check`가 통과한다.
