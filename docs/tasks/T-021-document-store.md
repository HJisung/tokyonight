# T-021 문서 저장소: 단일 버퍼와 다중 뷰

- 마일스톤: M2 파일·문서 코어
- 상태: draft
- 검수: 대기
- 의존: T-015
- 담당: 구현자

## 목표

한 문서를 여러 영역에서 열어도 내용이 일관되게 유지되는 프런트 문서 모델을 만든다.

## 범위

- 문서 식별(경로 또는 임시 메모 ID), 버퍼, 수정됨 상태, 디스크 기준 내용.
- 뷰 등록·해제, 마지막 뷰가 닫힐 때의 처리.

## 범위 밖

- 화면 분할 UI(T-040).

## 완료 기준

- 같은 문서의 두 뷰에서 번갈아 편집해도 내용이 일치함을 테스트로 확인한다.

## 작업 기록

- (진행하면서 결정·검증 결과·남은 문제를 여기에 적는다)
