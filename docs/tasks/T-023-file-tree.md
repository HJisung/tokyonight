# T-023 파일 목록 사이드바

- 마일스톤: M2 파일·문서 코어 (MVP)
- 상태: proposed
- 검수: 대기
- 의존: T-020, T-021, T-010
- 담당: 구현자

## 목표

왼쪽에서 폴더의 파일을 탐색하고 열고 만들고 이름을 바꾸고 지운다.

## 범위

- `src/features/file-tree/`. 연 폴더의 트리, 폴더 펼치기·접기, 파일을 누르면 본문에 연다.
- 추측: 열 수 없는 종류의 파일은 흐리게 보여 주고 열지 않는다(숨기지 않음).
- 새 파일(.md/.txt), 새 폴더, 이름 변경, 삭제(확인 후 휴지통). 우클릭 메뉴와 단축키.
- 이름이 겹치면 덮어쓰지 않고 그 자리에서 오류를 보여 준다.
- 열려 있는 문서의 이름을 바꾸면 문서 저장소의 경로도 바뀐다. 열려 있고 수정된 문서를 지우려 하면 한 번 더 묻는다.
- 파일이 많아도 느려지지 않게 목록을 가상화한다(@tanstack/react-virtual).

## 범위 밖

- 끌어서 이동, 외부에서 끌어다 놓기(T-043), 외부 변경 자동 반영(T-052). 목록 새로 고침은 수동 버튼으로 둔다.
- 검색(T-053).

## 완료 기준

- 테스트: 만들기·이름 변경·삭제가 ipc를 올바르게 부르고 이름 충돌 시 덮어쓰지 않는다.
- 수동 확인: 파일 1만 개 폴더에서 스크롤이 끊기지 않는다(PR에 기록).
- `pnpm check`가 통과한다.
