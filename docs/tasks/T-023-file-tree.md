- 검수: 대기

## 목표

## 범위

- 트리 표시(지원 파일만 열기 가능), 펼침 상태, 새 파일·새 폴더, 이름 변경, 삭제, 폴더 안 이동.
- 이름 충돌은 T-014 정책을 따른다.

## 범위 밖

- 외부에서 끌어다 놓기(T-043).
