# T-014 외부 변경·이름 충돌·복원의 세부 동작

- 마일스톤: M1 미정 사항 결정
- 상태: ready
- 의존: T-010
- 담당: 오케스트레이터+사용자

## 목표

데이터를 잃을 수 있는 상황의 동작을 구현 전에 못 박는다.

## 범위

- 외부 변경 감지 시: 수정 없음 → 자동 다시 읽기, 수정 있음 → 선택 UI 등 경우별 동작.
- 드래그 복사·이름 변경·새 파일의 이름 충돌 처리, 열려 있는 파일이 삭제·이동된 경우.
- 임시 메모 복원, 최근 작업 제공 시점과 시작 시 자동 열기 정책.
- `docs/decisions/0004-conflicts-and-restore.md`.

## 범위 밖

- 없음

## 완료 기준

- 경우별 표가 있고 '조용히 덮어쓰는 경로가 없음'이 확인되었다.
- 사용자가 확정했다.
