# T-020 파일 시스템 백엔드

- 마일스톤: M2 파일·문서 코어 (MVP)
- 상태: proposed
- 검수: 대기
- 의존: T-004
- 담당: 구현자

## 목표

프런트가 쓰는 파일 작업을 Rust 명령으로 제공한다. 사용자 파일을 손상시키지 않는 것이 최우선이다.

## 범위

- `src-tauri/src/fs/` 모듈과 Tauri 명령: 폴더 나열, 텍스트 읽기, 텍스트 쓰기, 파일·폴더 만들기, 이름 변경(이동 포함), 삭제.
- 쓰기는 원자적으로 한다(같은 폴더에 임시 파일을 쓰고 교체). 줄바꿈(CRLF/LF)과 BOM은 받은 내용 그대로 보존한다.
- UTF-8이 아닌 파일은 열지 않고 오류를 돌려준다(잘못 읽어 저장하면 손상되므로).
- 만들기와 이름 변경은 대상이 이미 있으면 덮어쓰지 않고 오류를 돌려준다.
- 삭제는 영구 삭제가 아니라 OS 휴지통으로 보낸다(`trash` crate, 신규 라이브러리).
- 접근 범위: 사용자가 대화상자로 고른 폴더와 파일만 허용 목록에 넣고, 그 밖의 경로는 거부한다. 폴더·파일 선택 대화상자는 `tauri-plugin-dialog`.
- 나열 결과에 종류를 표시한다: `.md`, `.txt`, 확장자 없음(일반 텍스트), 그 외(열 수 없음). 숨김 파일은 제외한다.
- `src/ipc/fs.ts`에 타입 있는 래퍼와 오류 종류(없음, 이미 있음, 권한, 범위 밖, UTF-8 아님, 기타).

## 범위 밖

- 변경 감시(T-052), 검색(T-053), 외부에서 끌어다 놓기(T-043).
- UI.

## 완료 기준

- 각 명령에 임시 폴더를 쓰는 Rust 테스트가 있다.
- 테스트로 확인: 허용 범위 밖 경로 거부, 기존 파일 덮어쓰기 거부, UTF-8 아닌 파일 거부, CRLF·BOM 파일의 읽기→쓰기 후 바이트 동일.
- `pnpm check`가 통과한다.
