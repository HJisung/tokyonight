# T-020 파일 시스템 백엔드

- 마일스톤: M2 파일·문서 코어
- 상태: draft
- 검수: 대기
- 의존: T-015
- 담당: 구현자

## 목표

프런트가 쓰는 파일 작업을 Rust 명령으로 제공한다.

## 범위

- 폴더 나열, 읽기, 원자적 쓰기(임시 파일 후 교체), 생성, 이름 변경, 이동, 삭제(휴지통).
- `.md`, `.txt`, 확장자 없는 파일 구분. 인코딩·줄바꿈 보존.
- 접근 범위 제한: 사용자가 연 폴더와 명시적으로 고른 파일만.

## 범위 밖

- 변경 감시(T-052), 검색(T-053).

## 완료 기준

- 각 명령에 Rust 테스트가 있다(임시 디렉터리 사용).
- 쓰기 도중 실패해도 원본 파일이 손상되지 않는다.
