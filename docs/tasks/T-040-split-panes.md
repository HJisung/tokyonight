# T-040 분할 영역

- 마일스톤: M4 작업 화면
- 상태: draft
- 검수: 대기
- 의존: T-021, T-010
- 담당: 구현자

## 목표

화면을 좌우·상하로 나누고 영역마다 문서를 표시한다.

## 범위

- 분할, 크기 조절, 닫기, 포커스 이동(단축키 포함).
- 같은 문서 또는 여러 문서를 나란히 표시.

## 범위 밖

- 없음

## 완료 기준

- 중첩 분할이 동작하고 같은 문서를 두 영역에서 편집하면 즉시 반영된다.

## 작업 기록

- (진행하면서 결정·검증 결과·남은 문제를 여기에 적는다)
