# T-040 분할 영역

- 마일스톤: M4 작업 화면 (MVP)
- 상태: ready
- 검수: 승인 (2026-11-12)
- 의존: T-024, T-010
- 담당: 구현자

## 목표

화면을 좌우·상하로 나누고 영역마다 문서를 표시한다.

## 범위

- `src/features/panes/`. 분할 배치는 트리 모델(Zustand)로 관리하고 화면은 react-resizable-panels로 그린다.
- 분할(오른쪽·아래), 크기 조절, 닫기, 영역 사이 포커스 이동. 단축키 포함.
- 추측: 영역 하나에 문서 하나를 보여 준다(영역 안의 문서 탭은 만들지 않음). 파일 목록에서 연 파일은 포커스된 영역에 열린다.
- 같은 문서를 여러 영역에 열 수 있고 편집이 즉시 반영된다. 빈 영역의 상태 화면.

## 범위 밖

- 영역을 끌어서 재배치, 배치 저장·복원(T-042).

## 완료 기준

- 단위 테스트: 분할, 닫기(형제 영역이 자리를 채움), 중첩 분할, 포커스 이동.
- 수동 확인: 같은 문서를 두 영역에서 번갈아 편집해도 내용이 같다.
- `pnpm check`가 통과한다.
