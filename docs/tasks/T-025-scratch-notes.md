# T-025 임시 메모

- 마일스톤: M2 파일·문서 코어 (MVP)
- 상태: ready
- 검수: 승인 (2026-11-12)
- 의존: T-024
- 담당: 구현자

## 목표

폴더 없이 바로 메모를 쓰고 나중에 파일로 저장한다.

## 범위

- 임시 메모는 파일이 없는 문서다. 기본 TXT, 버튼으로 MD로 전환(다시 TXT로도).
- `⌘N`/`Ctrl+N`으로 새 임시 메모. 폴더 작업 중에도 만들 수 있다.
- `⌘S`/`Ctrl+S`로 처음 저장할 때 위치와 이름을 고르고, 저장하면 일반 문서가 된다.
- 자동 복구가 MVP 범위 밖이므로, 내용이 있는 임시 메모를 닫거나 앱을 종료하려 하면 저장·버리기·취소를 묻는다.

## 범위 밖

- 자동 복구와 재실행 시 복원(T-051).

## 완료 기준

- 테스트: 임시 메모 → 저장 → 경로가 있는 문서로 전환, 종류 전환.
- 수동 확인: 내용이 있는 임시 메모가 있을 때 앱 종료를 시도하면 확인 창이 뜬다.
- `pnpm check`가 통과한다.
