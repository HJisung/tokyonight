# T-030 Markdown 서식 편집 기본

- 마일스톤: M3 Markdown 편집
- 상태: draft
- 검수: 대기
- 의존: T-012, T-024
- 담당: 구현자

## 목표

Markdown 문서를 서식이 바로 보이는 상태로 편집한다.

## 범위

- 제목, 문단, 목록, 체크리스트, 인용문, 코드 블록, 링크.
- Markdown 문법 입력(`# `, `- `, `> ` 등)이 서식으로 바뀐다.

## 범위 밖

- 표(T-032), 각주(T-033).

## 완료 기준

- 각 요소의 입력·편집·삭제가 동작하고 저장 결과가 표준 Markdown이다.
