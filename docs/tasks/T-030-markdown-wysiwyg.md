# T-030 Markdown 라이브 프리뷰

- 마일스톤: M3 Markdown 편집 (MVP)
- 상태: proposed
- 검수: 대기
- 의존: T-024
- 담당: 구현자(`impeccable` 스킬 사용)

## 목표

Markdown 문서를 서식이 바로 보이는 상태로 편집한다. 원문 텍스트는 사용자가 입력한 것 외에 바뀌지 않는다.

## 범위

- `.md` 문서에서 CodeMirror 데코레이션으로 서식 표시: 제목, 굵게·기울임·취소선, 목록, 체크리스트(눌러서 토글), 인용문, 코드 블록·인라인 코드, 링크(`⌘`/`Ctrl`+클릭으로 열기), 구분선.
- 커서가 있는 줄이나 요소는 원문 문법을 그대로 보여 준다.
- 목록·체크리스트·인용문에서 Enter로 이어 쓰기.
- 표, 각주, HTML, frontmatter 등 지원하지 않는 문법은 원문 그대로 보여 준다.
- 왕복 테스트용 문서를 `fixtures/markdown/`에 둔다.

## 범위 밖

- 표 편집(T-032), 각주 표시(T-033), 이미지 표시, 코드 구문 강조.
- 서식 버튼 도구 모음.

## 완료 기준

- 테스트: fixtures의 모든 문서를 열고 수정 없이 저장하면 바이트가 동일하다.
- 테스트: 체크리스트 토글은 해당 `[ ]` 한 글자만 바꾼다.
- PR에 스크린샷이 있고 `pnpm check`가 통과한다.
- 사용자가 편집 느낌을 확인했다. 만족스럽지 않으면 Tiptap 대안을 검토하는 task를 만든다.
