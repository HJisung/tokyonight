# T-026 새 파일 만들기와 폴더 밖 파일 열기

- 마일스톤: M2 파일·문서 코어 (MVP)
- 상태: proposed
- 검수: 대기
- 의존: T-023, T-024
- 담당: 구현자

## 목표

이름과 위치를 정해 새 `.md`/`.txt`를 만들고, 폴더 밖의 파일도 현재 창에서 연다.

## 범위

- 새 파일: 저장 대화상자로 위치·이름·종류를 고른다. 폴더가 열려 있지 않아도 된다.
- 파일 열기(`⌘O`/`Ctrl+O`): 폴더 밖의 `.md`, `.txt`, 확장자 없는 파일을 연다.
- 폴더 밖 문서는 제목에 전체 경로를 보여 주어 구분한다.

## 범위 밖

- 폴더 밖 파일 목록을 사이드바에 따로 보여 주기.

## 완료 기준

- 두 흐름이 동작하고, 폴더 밖 문서도 편집·저장된다.
- `pnpm check`가 통과한다.
