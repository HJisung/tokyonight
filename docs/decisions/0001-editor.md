# 0001 편집기: CodeMirror 6 라이브 프리뷰로 시작

- 날짜: 2026-11-12
- 상태: 확정(되돌릴 수 있음)
- 결정자: 사용자

## 결정

Markdown 편집기는 CodeMirror 6 위에 라이브 프리뷰 방식으로 만든다. 원문 텍스트가 그대로 문서이고, 커서가 없는 부분만 서식으로 보인다. TXT와 확장자 없는 파일도 같은 CodeMirror를 일반 텍스트 모드로 쓴다.

Tiptap(ProseMirror) 블록 편집은 대안으로 남겨 둔다. MVP에서 써 보고 편집 느낌이 만족스러우면 대안에서 제외하고, 아니면 Tiptap으로 다시 시도한다.

## 이유

- 저장할 때 변환이 없어 지원하지 않는 문법을 잃을 위험이 거의 없다.
- 원문 모드는 서식 표시를 끄는 것으로 구현된다.
- 한 문서를 여러 분할 영역에서 여는 구성이 CodeMirror의 상태 모델과 잘 맞는다.

## 영향

- 프로토타입 비교(T-011)는 하지 않는다.
- 표 편집 UI(T-032)는 직접 만들어야 한다. MVP 범위 밖이다.
- 편집기를 바꿀 가능성이 있으므로 편집기는 `src/features/editor/` 안에 가두고, 다른 기능은 이 기능이 내보내는 인터페이스(문서 내용 읽기·쓰기, 변경 알림)만 쓴다.
