# 0003 작업 상태는 폴더 안 숨김 디렉터리에 저장

- 날짜: 2026-11-12
- 상태: 확정
- 결정자: 사용자

## 결정

- 워크스페이스 목록과 분할 배치 등 폴더에 속한 상태는 열린 폴더 안의 숨김 디렉터리에 저장한다. 폴더를 옮기거나 동기화하면 배치도 함께 간다.
- 폴더에 속하지 않는 데이터(임시 메모 복구, 최근 작업 목록)는 OS 앱 데이터 디렉터리에 둔다.

## 아직 정하지 않은 것

- 숨김 디렉터리의 이름. 제품명이 정해지지 않았으므로 구현(T-042) 전에 정한다.
- 파일 형식과 스키마, 버전 필드. T-042에서 정한다.
- 파일 목록과 검색에서 이 디렉터리를 숨기는 규칙.
